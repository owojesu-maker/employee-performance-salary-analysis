# employee-performance-salary-analysis

Employee Performance and Salary Analysis Using Excel

Project Overview
This project explores employee information to understand salary distribution and employee performance.

Objectives
- Analyse employee salaries.
- Calculate the annual wage bill.
- Examine employee performance ratings.
- Identify high-performing employees.
- Examine employee retention and exits.

Tool Used
- Microsoft Excel

Skills Demonstrated
- Data cleaning
- Excel formulas
- Data analysis
- Data interpretation

 Project Status
